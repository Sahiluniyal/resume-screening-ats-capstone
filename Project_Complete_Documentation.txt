1. INTRODUCTION
==========================================================

This project presents an Enterprise Resume Screening and Role Matching System developed as part of the Data Science with GenAI Capstone Project.

The objective of the project is to automate the initial recruitment process using Natural Language Processing (NLP), Feature Engineering, and an Applicant Tracking System (ATS) inspired scoring methodology.

Modern organizations receive thousands of resumes every month for various technical and non-technical roles. Recruiters often spend several hours manually reviewing resumes to identify suitable candidates.

Traditional ATS software mainly depends on keyword matching, which is not always capable of understanding the contextual meaning of candidate skills or project experience.

For example, two candidates may possess the same technical skills but describe them differently in their resumes. A keyword-based system may rank one candidate highly while completely ignoring another equally qualified applicant.

To address these limitations, this project combines business-driven feature engineering with Natural Language Processing techniques.

The developed system performs automatic candidate evaluation, compares resumes against predefined enterprise job roles, generates ATS-style Fit Scores, and recommends the best candidates for recruiters.

Rather than replacing recruiters, this system acts as a decision-support tool that significantly reduces manual effort while improving consistency in resume evaluation.

24. TF-IDF VECTORIZATION
==========================================================

TF-IDF stands for

Term Frequency – Inverse Document Frequency.

Purpose

Convert resume text into numerical vectors.

Machine learning algorithms cannot process raw text.

TF-IDF converts every resume into numbers while assigning importance to words.

----------------------------------------------------------
Term Frequency (TF)
----------------------------------------------------------

Measures how frequently a word appears in a document.

Words appearing multiple times receive higher weight.

----------------------------------------------------------
Inverse Document Frequency (IDF)
----------------------------------------------------------

Measures how rare a word is across the complete dataset.

Words appearing in almost every resume receive lower importance.

Rare technical terms receive higher importance.

Example

Python

TensorFlow

Kubernetes

Spark

These words contribute more than

the

is

and

because they help distinguish candidate expertise.

==========================================================
25. COSINE SIMILARITY
==========================================================

After TF-IDF conversion, resumes become vectors.

Enterprise job roles are also converted into vectors.

The project compares:

Resume Vector

with

Role Vector

using Cosine Similarity.

Cosine Similarity returns values between:

0

and

1

Interpretation

0

No similarity

0.50

Moderate similarity

1

Perfect similarity

The project multiplies these values by 100 to generate percentage similarity.

Business Importance

Recruiters can understand similarity scores more easily when expressed as percentages.

55. CONCLUSION
==========================================================

This capstone project successfully demonstrates the application of Data Science, Natural Language Processing, and Business Analytics in solving enterprise recruitment problems.

The solution begins with structured resume data, performs validation and preprocessing, engineers meaningful business features, compares candidate profiles using TF-IDF and Cosine Similarity, calculates a Hybrid ATS Score, and finally generates recruiter-friendly recommendations through an interactive Streamlit dashboard.

Unlike traditional keyword-based resume screening systems, the proposed solution evaluates candidates using multiple dimensions including technical capability, experience, education, leadership, project relevance, and ATS readiness.

The modular architecture, explainable scoring mechanism, and interactive dashboard make the solution practical, scalable, and easy to understand.

Overall, this project demonstrates how AI-assisted recruitment systems can improve hiring efficiency, reduce recruiter workload, and support better talent acquisition decisions.
