# Detailed Resume Bullet Points

- Developed an enterprise-style **Resume Screening and Role Matching System** using **Python, NLP, Scikit-learn, Pandas, and Streamlit**, automating candidate evaluation across **5,000 structured resumes**.

- Validated and preprocessed a dataset containing **5,000 candidate profiles** and **34 structured resume attributes**, performing missing value handling, duplicate checks, text normalization, and ATS data quality validation.

- Engineered **15+ business-driven features**, including **Resume Quality Score, ATS Readiness Score, Technical Strength Score, Leadership Score, Domain Alignment Score, Candidate Quality Index (CQI),** and **Role Readiness Score** to improve candidate evaluation.

- Built an NLP-based matching pipeline using **TF-IDF Vectorization** and **Cosine Similarity** to compare resume content with **5 enterprise job role definitions**, enabling semantic candidate-role matching beyond simple keyword searches.

- Designed a **Hybrid ATS Scoring Engine** combining **skill matching, experience alignment, project relevance, education, ATS readiness, and leadership indicators** to generate explainable **0–100 Fit Scores**.

- Classified candidates into **4 recruiter-friendly recommendation categories** (**Highly Recommended, Recommended, Consider, Not Suitable**) to support faster and more consistent shortlisting.

- Developed an interactive **Streamlit Dashboard** featuring **Executive Overview, Candidate Search, Role Matching, Top Candidates, and Recruitment Analytics**, enabling recruiters to visualize hiring insights and candidate rankings.

- Generated automated project deliverables including **candidate ranking reports, validation reports, and enterprise role definitions**, creating a reusable recruitment analytics framework.

# LinkedIn Project Description

Developed an end-to-end **Resume Screening and Role Matching System** for TalentBridge Solutions using **Python, Natural Language Processing (NLP), Scikit-learn, and Streamlit**. The solution processed **5,000 candidate profiles** with **34 structured resume attributes**, engineered **15+ recruiter-focused features**, matched candidates across **5 enterprise job roles** using **TF-IDF and Cosine Similarity**, and generated explainable **ATS Fit Scores** through a Hybrid Scoring Engine. The project also included an interactive recruiter dashboard for candidate search, role matching, analytics, and hiring recommendations.
